# 因子アシスト（Android）

ウマ娘の因子選択画面をスクロールするだけで、欲しい因子がいくつ付いているかを数えて表示するアプリです。
あらかじめ「欲しい因子」をプリセットとして登録しておくと、読み取った因子を
**必須／重要／必要** に分けて数え、画面上の因子にも色付きの枠を重ねて表示します。

- 画面を読み取って数えるだけのツールです。**ゲームの操作は一切行いません。**
  タップやスワイプの自動化、通信の傍受や改変、ゲームのデータやファイルへのアクセスはしていません。
- 読み取りはAndroidの画面共有（あなたが許可した画面だけ）を使い、認識はすべて端末の中で行います。
  画面の内容が外部に送信されることはありません。
- ファン制作の非公式ツールです。株式会社Cygamesおよび umacapture とは関係ありません。

## 必要なもの

- Android 14 以上のスマートフォン（64bit ARM。最近の機種はほぼ該当します）

## インストール

1. [Releases](https://github.com/teitetsu-lab/factor-assist-android/releases) から最新の `app-release.apk` をダウンロードします。
2. ダウンロードしたファイルを開いてインストールします。
   「提供元不明のアプリ」の許可を求められたら、ブラウザやファイルアプリに許可を出してください。
3. 新しい版は、同じ手順で上からインストールすれば更新できます（プリセットや設定は残ります）。

## 使い方

### 1. プリセットを作る

アプリを開き、プリセットを作成して欲しい因子を登録します。
因子の一覧から選んで追加でき、検索欄で絞り込めます。因子ごとに必要な星の数も指定できます。

- **簡易プリセット**：必須・重要・必要・本育成で取得可能 の4段階で分けます。枠の色は 必須が赤、重要が黄、必要が青、本育成で取得可能が紫です。
- **詳細プリセット**：0（最優先）〜7 の8段階で分けます。枠の色は 赤・橙・黄・緑・青・藍・紫 の順です。

作ったプリセットは、共有コード・コードファイル・QR画像のどれかで書き出して、他の人に渡せます。
受け取ったプリセットは、同じ3つの形から取り込めます。

### 2. 読み取りを始める

1. アプリで「フローティング表示」を許可すると、画面の端に「☰」と「開始」のボタンが出ます。
2. 「開始」を押すとゲームが起動し、画面共有の確認が出ます。**画面全体ではなく「ウマ娘」のアプリだけ**を選んでください。
3. 因子選択画面を開いて、リストを上から下までゆっくりスクロールします。
   読み取った結果が小さなウィンドウに「必須 ○ / 重要 ○ / 必要 ○」の形で表示されます。

### 3. 結果を見る

- 結果のウィンドウをタップすると、ページ（元因子・再獲得因子1〜9）ごとの因子名と星の数が見られます。
- 表示設定で「因子に枠を付ける」をオンにすると、画面上の因子に優先度の色の枠が付きます。
  星が足りない因子は、枠の左側が灰色になります。
- 結果は「停止」しても残ります。消すときはメニューの「結果をリセット」を押してください。

### ボタンと設定

- 「☰」：プリセットの切り替え、表示設定、結果のリセットなど。
- 「開始／停止」：読み取りの開始と一時停止。停止中はスマホの負担がかかりません。
- 結果のウィンドウ・ボタン・処理状況の表示は、それぞれドラッグして好きな位置に動かせます。
- 表示設定では、結果の文字の大きさや色、枠の表示、結果ウィンドウをタップ・2回タップ・長押ししたときの動作を変えられます。

## 困ったとき

- **枠や読み取りの位置がずれる**：アプリの「位置合わせ」から、因子選択画面のスクリーンショットを使って調整できます。
- **メニューが画面の外に出てしまった**：通知から呼び戻せます。
- **読み取りが遅い・スマホが熱い**：表示設定の「認識」で、1秒あたりの読み取り回数を減らしてください。
- **アプリを終わらせたい**：メニューの「終了」か、通知から終了できます。

## 使っているデータとライセンス

因子名と星の読み取りには、[umasagashi/umacapture](https://github.com/umasagashi/umacapture) のモデルと因子データを使っています。
原文は同梱の [umacapture-modules-LICENSE.md](app/src/main/assets/umacapture-modules-LICENSE.md) と
[umacapture-LICENSE.txt](app/src/main/assets/umacapture-LICENSE.txt)（MIT）です。

- `factor.onnx` / `factor_rank.onnx`：umacapture の作者が作成した学習済みモデルで、パブリックドメインです。
- `labels.json` / `factor_info.json` / `factor_tag.json`：ウマ娘のゲーム内テキスト（株式会社Cygamesの著作物、一部は登録商標）を含みます。
  umacapture の作者はこれらの部分に権利を主張しておらず、本リポジトリも何ら権利を主張しません。
