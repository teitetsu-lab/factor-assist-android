# 因子アシスト（Android）

ウマ娘の画面をスクロールするだけで、欲しい因子やスキルを見つけて教えてくれるアプリです。
あらかじめ「欲しい因子」をプリセットとして登録しておくと、次のことをします。

- **因子選択画面**：読み取った因子を **必須／重要／必要／本育成** に分けて数え、画面上の因子に優先度の色を重ねて表示します。
- **スキル取得画面**：同じプリセットを使って、登録してある白因子と同じ名前のスキルに色を付けます。
  「本育成で取得可能」に登録した因子のスキルも、育成中のスキル取得画面でそのまま見つけられます。

注意：
- 画面を読み取って表示するだけのツールです。**ゲームの操作は一切行いません。**
  タップやスワイプの自動化、通信の傍受や改変、ゲームのデータやファイルへのアクセスはしていません。
- 読み取りはAndroidの画面共有（あなたが許可した画面だけ）を使い、認識はすべて端末の中で行います。
  画面の内容が外部に送信されることはありません。
- ファン制作の非公式ツールです。株式会社Cygamesおよび umacapture とは関係ありません。

## 必要なもの

- Android 14 以上のスマートフォン（64bit ARM。最近の機種はほぼ該当します）

## インストール

1. [Releases](https://github.com/teitetsu-lab/factor-assist-android/releases) から最新の `app-release.apk` をダウンロードします。
2. ダウンロードしたファイルを開いてインストールします。
   「提供元不明のアプリ」の許可を求められたら、ブラウザやファイルアプリに許可を出してください。
3. 新しい版は、同じ手順で上からインストールすれば更新できます（プリセットや設定は残ります）。

## 使い方

### 1. プリセットを作る

アプリを開き、「新規プリセット」で作って「プリセットを編集」で欲しい因子を登録します。
因子の一覧から選んで追加でき、検索欄で絞り込めます。因子ごとに必要な星の数も指定できます。

- **簡易プリセット**：必須・重要・必要・本育成で取得可能 の4段階で分けます。色は 必須が赤、重要が黄、必要が青、本育成で取得可能が紫です。
- **詳細プリセット**：0（最優先）〜7 の8段階で分けます。色は 赤・橙・黄・緑・青・藍・紫 の順です。

作ったプリセットは「プリセットを書き出す」から、共有コード・QR画像・ファイルのどれかで他の人に渡せます。
受け取ったプリセットは「プリセットを取り込む」から、同じ3つの形で取り込めます。

### 2. 読み取りを始める

1. トップ画面の「▶ 認識開始」を押します。初回はフローティング表示（ほかのアプリの上に表示）の許可を求められます。
2. 画面共有の確認が出たら、「単一のアプリ」で **ウマ娘** を選びます。
3. ゲームの上にボタンと結果のウィンドウが出て、読み取りが始まります。
4. 因子選択画面やスキル取得画面を開いて、リストをゆっくりスクロールします。

一度つないだら、停止しても共有はつながったままなので、次の開始では確認は出ません。

### 3. 因子選択画面

- 結果のウィンドウに、ページ（元因子・再獲得因子1〜9）ごとに「必3 重2 要1 本2 未5」のように数が出ます。
- 画面上の因子に優先度の色の枠が付きます（表示設定の「因子に枠を付ける」でオフにできます）。星が足りない因子は灰色が混ざります。
- 結果のウィンドウをタップすると、ページごとの因子名と星の数が見られます。

### 4. スキル取得画面

- 読み取ったスキルのうち、プリセットに登録してある因子と同じ名前のスキルに、その優先度の色の枠が付きます。
  枠の左上には 必／重／要／本（詳細プリセットなら 0〜7）の札が付きます。
- 名前の下には、読み取ったスキル名が表示されます（表示設定で文字の大きさや位置を変えられます）。
- メニューの「動作モード」で、プリセットの色で枠を付ける（プリセットのみ）か、読めた行に緑の枠を付けるだけ（両方なし）かを選べます。
- 結果のウィンドウをタップすると、読み取ったスキルの一覧が見られます。

### 5. 因子とスキルの切り替え

- メニュー（☰）の一番上の「因子｜スキル」で切り替えられます。結果のウィンドウを横に払っても切り替わります。
- **自動切り替え**：因子選択画面とスキル取得画面を見分けて、モードを自動で切り替えます。
  切り替わると画面の真ん中に「因子モード」「スキルモード」と出ます。表示設定の「認識」でオフにできます。
- 因子とスキルの結果は別々に残るので、切り替えても消えません。

### 6. 結果のリセットと履歴

- 結果を消すときは、メニューの「結果をリセット」を押します。今のモードの結果だけが消えます。
- リセットする前の結果は、日時付きで自動的に保存されます。
  メニューの「その他」から、**1つ前の結果を呼び出す** や **結果の履歴** で元に戻せます。戻した結果の続きから読み取れます。

## 設定

トップ画面の「アプリ設定」から変えられます。

- **全般**
  - テーマ（ライト／ダーク／端末に従う）
  - 認識開始を押したとき：すぐ読み取りを始める／停止状態で待つ

  - 因子画面の表示：枠／★の左に文字
  - スキル取得画面の表示：枠／名前の下に線
- **フローティング**：ボタンの形（カプセル・丸ボタン・四角・ミニ・ボール・エッジ）、ボールとエッジの開き方、大きさ、色、不透明度

## 困ったとき

- **枠や読み取りの位置がずれる**：トップ画面の「読み取り位置の調整」で、因子選択画面・スキル取得画面のスクリーンショットを使って調整できます。
  文字や線を表示する位置もここで動かせます。読み取りに使う場所に重なると赤く表示されます。
- **メニューが画面の外に出てしまった**：通知から呼び戻せます。
- **読み取りが遅い・スマホが熱い**：表示設定の「認識」で、「毎秒の文字認識目標回数」を減らしてください（15回くらいでも十分読めます）。枠はこの回数に関係なく画面に合わせて動きます。
- **アプリを終わらせたい**：トップ画面の「終了する」、メニューの「終了」、または通知から終了できます。

## 使っているデータとライセンス

因子名・星・スキル名の読み取りには、[umasagashi/umacapture](https://github.com/umasagashi/umacapture) のモデルとデータを使っています。
原文は同梱の [umacapture-modules-LICENSE.md](app/src/main/assets/umacapture-modules-LICENSE.md) と
[umacapture-LICENSE.txt](app/src/main/assets/umacapture-LICENSE.txt)（MIT）です。

- `factor.onnx` / `factor_rank.onnx` / `skill.onnx`：umacapture の作者が作成した学習済みモデルで、パブリックドメインです。
- `labels.json` / `factor_info.json` / `factor_tag.json` / `skill_info.json` / `skill_tag.json`：ウマ娘のゲーム内テキスト（株式会社Cygamesの著作物、一部は登録商標）を含みます。
  umacapture の作者はこれらの部分に権利を主張しておらず、本リポジトリも何ら権利を主張しません。

文字の読み取りの確認には、Google の ML Kit（端末内で動く文字認識）を使っています。
